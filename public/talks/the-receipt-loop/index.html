Merge is a human decision, sized by blast radius.

low

  • No shared contract
  • Easily reverted
  • Verify check is green

Gate: Agent may proceed directly to code review without extra approvals.

owned

  • Touches one team's code
  • Isolated feature or logic change
  • Evidence receipt attached

Gate: Code-owner review required before merge.

blast radius

  • Shared library, schema, auth, infra
  • High customer / platform impact

Gate: Extra reviewer + required CI check + staged rollout.

Automation raises the ceiling.
Proof and review set the safe one.

Throughput Potential

  • Unattended background agents
  • Concurrent execution across isolated branches
  • Concurrency raises capacity; measure accepted throughput and rework.

Risk: 100 agents without proof = slop and regressions.

The Verification Ceiling

  • Deterministic test and screenshot receipts
  • Independent read-only cloud review
  • Risk-tiered human merge gates

Result: Higher throughput with evidence-backed review.

Poteto's 2,000 PRs/month is her case study, not our target. Our target is the mechanism that made it safe.
